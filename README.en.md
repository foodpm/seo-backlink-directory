## How to use

1. Start with 10 relevant directories and make sure your product page can absorb the traffic.
2. Write one genuinely useful tutorial, publish it on dev.to or Hashnode, then cross-post to Chinese communities.
3. Once you have a demo, pick two launch platforms and stagger the launches.
4. Add 3–5 new sites from the list every month.
5. Review quarterly: which links actually brought visits.

Aim for **3–5 submissions per week**, working through the categories in order rather than batch-submitting. Copy the [submission checklist](docs/checklist-en.md) into your notes and tick items off. Use four statuses only: Submitted / Live / Rejected / Needs manual follow-up.

Relevance always beats volume.

## Contributing via PR

1. Fork this repository and create a branch.
2. Add one row to the matching category table in both `README.md` and `README.en.md`, keeping the same order and URL.
3. Add the same entry to `docs/checklist-zh.md` and `docs/checklist-en.md`.
4. Keep the site's original name. Describe the submission method, whether review is required, and whether a reciprocal link is needed. Do not make unverifiable promises.
5. Open a PR with the site's purpose, URL, and your experience using it.

Not accepted: pure ads, unreachable sites, sites unrelated to SEO/backlinks, or obvious link farms.
