### 分类依据

原始数据只有一个「外链资源」大类，没有子分类。这里沿用整理文章里的分法，按**提交成本**和**能拿到什么**重新归为 6 类：

1. **目录站 / AI 导航**：填表、等审核，拿基础收录。
2. **新品发布平台**：一次性曝光，适合有演示版的产品。
3. **内容与社区平台**：需要先写对别人有用的内容，最慢但最自然。
4. **外链聚合清单**：别人的清单，用来筛选目标，不是用来批量刷。
5. **付费外链平台**：有预算再碰，买量和速度，不买相关性。
6. **品牌页 / 顺手能挂链接**：占品牌词，十分钟能填完。

### 怎么用

1. 先做 10 个相关目录，确认产品页能接住流量。
2. 写 1 篇真正有用的教程，发到 dev.to 或 Hashnode，再同步到中文社区。
3. 产品有演示版后，挑 2 个发布平台错开发布。
4. 之后每月从清单里挑 3–5 个新站，持续补充。
5. 每季度回看一次，哪些链接带来了真实访问。

建议每周做 **3–5 条**，按分类顺序推进，不要一次性批量提交。可以复制 [中文清单](docs/checklist-zh.md) 或 [English checklist](docs/checklist-en.md) 到笔记里逐条打勾。状态只用四种：已提交待审核 / 已上线 / 被拒 / 需人工处理。

判断标准始终是相关性，不是数量。

### 如何提交 PR 补充新站点

1. Fork 本仓库并新建分支。
2. 在对应分类的中英文文件里各加一行，编号接着该分类最后一个编号往下排，中英文编号必须一致。
3. 同步在 `docs/checklist-zh.md` 和 `docs/checklist-en.md` 里加同样的条目。
4. 站点名保留原名；说明写清楚提交方式、是否审核、是否需要返链，不要写无法验证的承诺。
5. 提交 PR，说明站点用途、网址和你的使用体验。

不接受：纯广告、无法访问、与 SEO / 外链完全无关、或明显是链接农场的站点。

### Why these categories

The source data has a single "backlink resources" category with no subcategories. This repository follows the grouping used in the original write-up and reclassifies by **submission cost** and **what you get**:

1. **Directories / AI navigation**: fill a form, wait for review, earn a basic listing.
2. **Product launch platforms**: one-shot exposure; best with a demo.
3. **Content & community platforms**: write something genuinely useful first; slowest but most natural.
4. **Backlink aggregator lists**: other people's lists; use them to shortlist, not to blast.
5. **Paid backlink platforms**: only with a budget; they sell volume and speed, not relevance.
6. **Brand pages / easy placements**: occupy brand keywords; ten minutes each.

### How to use

1. Start with 10 relevant directories and make sure your product page can absorb the traffic.
2. Write one genuinely useful tutorial, publish it on dev.to or Hashnode, then cross-post to Chinese communities.
3. Once you have a demo, pick two launch platforms and stagger the launches.
4. Add 3–5 new sites from the list every month.
5. Review quarterly: which links actually brought visits.

Aim for **3–5 submissions per week**, working through the categories in order rather than batch-submitting. Copy the [Chinese checklist](docs/checklist-zh.md) or the [English checklist](docs/checklist-en.md) into your notes and tick items off. Use four statuses only: Submitted / Live / Rejected / Needs manual follow-up.

Relevance always beats volume.

### Contributing via PR

1. Fork this repository and create a branch.
2. Add one row to the corresponding Chinese and English category files, continuing the numbering from the last entry in that category. Numbers must match across languages.
3. Add the same entry to `docs/checklist-zh.md` and `docs/checklist-en.md`.
4. Keep the site's original name. Describe the submission method, whether review is required, and whether a reciprocal link is needed. Do not make unverifiable promises.
5. Open a PR with the site's purpose, URL, and your experience using it.

Not accepted: pure ads, unreachable sites, sites unrelated to SEO/backlinks, or obvious link farms.
